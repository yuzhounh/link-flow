# LinkFlow - 私人文件传输助手

> 专为「手机 ↔ 电脑」打造的极简私人聊天传输工具。
> 像微信“文件传输助手”一样随手丢文字、截图、照片、视频、PDF、ZIP，但不依赖微信/QQ，零外部云端，局域网极速直连。

## ✨ 核心特性

- **双向私人聊天时间线**：手机与电脑双向即时呈现，清晰的时间戳与设备来源标识。
- **手机免装 App**：电脑启动服务，手机（如 Redmi K80 Pro）扫码即可在浏览器打开；支持 PWA「添加到主屏幕」获得原生 App 级沉浸体验。
- **全格式多媒体支持**：
  - 📝 **文字**：一键复制，手机端发送文字可选**自动同步至 Windows 剪贴板**。
  - 🖼️ **图片与各类文件**：图片作为标准文件无损直发，不生成任何缩略图，以极简文件卡片统一呈现，支持一键下载与本地资源管理器定位。
  - 📄 **PDF**：PyMuPDF 自动抽取第一页封面渲染缩略图，附带文件大小与下载。
  - 🎥 **视频 & 音频**：原生 HTML5 播放器，即点即播。
  - 📦 **任意文件**：ZIP、Word、代码文件等分类展示，PC 端支持**一键在资源管理器中定位**。
- **快捷交互**：
  - 💻 **截图即发**：在窗口中直接按 `Ctrl + V`，剪贴板中的截图秒速上传。
  - 📂 **拖拽上传**：将任何文件直接拖入浏览器窗口即可投放。
  - 📷 **手机直拍**：手机端点击相机图标直接调用后置/前置摄像头拍照上传。
  - 🔍 **即时搜索**：按回车或输入关键字实时过滤历史记录。
  - 🌓 **深色/浅色模式**：自由切换，夜间使用更舒适。
- **轻量可靠 & 零外部安装依赖**：
  - 基于 Anaconda 自带环境（Python 3.13 + Tornado + SQLite + Pillow + PyMuPDF + Win32 ctypes）。
  - 数据全部保存在本地 `data/messages.db` 和 `data/files/YYYY-MM/`，隐私安全无忧。

## 🚀 启动与使用方法

### 方式一：后台静默模式 (日常推荐，完全无黑框)
- **启动**：双击 **`start.vbs`**（无控制台黑框窗口，后台静默常驻，自动拉起浏览器）。
- **停止**：双击 **`stop.vbs`**（静默停止后台服务，并弹出 2 秒自动关闭的停止确认通知）。

### 方式二：控制台窗口模式 (适合查看实时日志)
- **启动**：双击 **`Start with Console.bat`**（打开控制台窗口，输出实时访问日志）。
- **停止**：双击 **`Stop with Console.bat`**（控制台终止并回显停止结果）。

### 手机端连接：
1. 确保手机与电脑连接到同一个 Wi-Fi。
2. 在电脑界面点击右上角 **「扫码连接」**。
3. 使用手机相机或浏览器扫描屏幕二维码，即可开始双向传输！
