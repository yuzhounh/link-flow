# LinkFlow Android 配套客户端

Android 10 及以上可安装，通用 APK，无 CPU 架构限制。版本 0.3.12，包名 `com.yuzhounh.linkflow`。

这是 Windows LinkFlow 的手机客户端，电脑需要持续运行 LinkFlow，手机与电脑需在可互通的局域网中。界面、消息和文件由电脑提供；APK 不包含 Windows 服务端，不支持手机独立作为传输服务器。

## 使用

0.3.12 接收完成后卡片不再显示“已接收”状态行，也不再弹出“开始接收”“已接收”提示；接收失败的原因直接显示在卡片中。手机端长按文字或文件卡片弹出圆角操作菜单（文字：复制、选择文字、删除；文件：复制链接、重新接收、接收压缩图、删除），单击不再弹出按钮。切换月份与实时消息不再提示，查看其他月份时收到新消息提示“有新消息，请返回实时消息查看”。提示统一为圆角样式，普通提示浅蓝、错误提示浅红，网页与 APK 一致。Windows 端与 APK 版本号统一为 0.3.12。

0.3.11 手机右侧操作按状态切换：接收、接收进度、分享、失败重试、本地文件删除后重新接收。分享使用系统分享面板及本地文件 URI；长按菜单保留复制链接、重新接收、接收压缩图和删除。原图与压缩图单独记录。已接收卡片点击一次后恢复默认背景，保留“已接收”提示；确认状态按本次下载 ID 持久保存，重新接收完成可再次高亮。电脑离线时已接收文件可分享，未接收项等待上线。

0.3.10 将四个配对按钮统一为浅色背景深色文字。手机发送文件时，电脑自动保存并实时显示接收进度；电脑发出的新文件在手机 APP 自动下载，无需点击，恢复连接后按持久化接收位置补收，已下载文件不重复保存或自动打开。首次启用建立起点，不批量下载旧历史文件；旧文件仍可点击接收。接收端卡片按真实字节进度填充浅蓝色背景，完成后整卡浅蓝并显示“已接收 100%”，同时提示“已接收”；失败显示原因。大小未知时不伪造百分比。APK 自动接收但不自动安装。手机网页版受浏览器下载限制，自动保存功能由 Android APP 提供。

0.3.9 配对窗口四按钮按“粘贴、清空、连接、取消”单行等宽排列，连接使用主色。每次打开仅读取一次剪贴板，有效配对链接自动填入并明确提示，其他内容不覆盖原输入；手动粘贴替换全部文本，空剪贴板保留原输入，无效链接禁用连接。连接前检查电脑服务，失败保留输入，成功后才保存新配对；取消返回连接管理。

0.3.8 将设置标题简化为“设置”。APP 读取自身安装包 versionName，网页和电脑端读取服务端程序集版本，避免 APP 显示旧电脑版本。全局清空仍仅电脑主机可执行，手机端不提供删除所有设备共享记录的入口。

1. 将 `../dist/LinkFlow-0.3.12-android.apk` 发送到手机并覆盖安装。
2. 电脑运行 LinkFlow，打开「扫码连接」。
3. 手机打开 App，点「摄像头扫码连接」，授权相机并扫描电脑二维码；也可粘贴完整配对链接。
4. 配对链接保存在应用私有存储，下次自动连接。连接后直接显示网页界面；通过主界面右上角第一个「连接管理」按钮重连或重新配对。

0.3.7：删除月份栏重复的“返回实时”按钮，再次点击日历即可切回；验证 320/393/768px 下月份栏单行且切换正常。APK 来源权限提示改为 20dp 圆角，系统安装页仍由 Android 控制。删除设置底部重复的连接入口，保留主界面连接管理。Android 构建与 Lint 通过。

0.3.6：扫码使用独立竖屏 Activity；连接管理选项带左侧图标。配对链接窗口左右留白 24dp，未编辑时单行省略，点击后可编辑完整链接；“清空”仅清除当前输入，“粘贴”读取并校验剪贴板链接后直接替换，不自动读取剪贴板。从连接管理进入的配对窗口取消或系统返回会回到连接管理，未提交的改动不影响已保存配对。

连接管理与配对弹窗使用统一 20dp 圆角，输入区域和清空/粘贴按钮也采用圆角。0.3.6 已在 Android 15 模拟器验证竖屏扫描界面、图标菜单、清空/粘贴及取消/系统返回恢复上级菜单；真实摄像头识别能力沿用 ZXing。

支持网页文字传输、系统文件选择上传、拍照回传及系统下载管理器保存文件到 `Download/LinkFlow/`。扫码解码器随包提供，不依赖 Google Play 服务。网页功能随电脑端版本同步更新。

## 构建

需要 JDK 17+、Android SDK 35 和 Build Tools，以及 Gradle 下载的 Android Gradle Plugin 8.13.0。

在此目录的 `local.properties` 中配置 `sdk.dir`。本地 `signing.properties` 指定 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`。签名文件与密码均已忽略，不提交 Git；保留它们才能签发可覆盖安装的后续版本。

```powershell
.\gradlew.bat --no-daemon assembleRelease lintRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`。

Windows 如遇 JDK UnixDomainSockets / loopback 错误，为 `JAVA_TOOL_OPTIONS` 设置 `-Djdk.net.unixdomain.tmpdir="短路径临时目录"`；本机使用工作区 `tmp/lf`。

应用声明网络及相机权限，相机仅在扫码或拍照时申请。禁用备份，允许现有局域网 HTTP 服务。配对令牌保留在应用私有存储中。文件下载仅允许当前配对服务器，外部网页交给浏览器打开，不添加原生 JavaScript 接口。
